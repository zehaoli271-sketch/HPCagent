# 实时作业图

在仓库根目录启动本地服务。

```powershell
python -m frontend.server
```

打开 [本地页面](http://127.0.0.1:8765/)，点击右上角「连接 SJTU HPC」，输入有作业读取权限的访问令牌。令牌由后端进程管理，页面通过会话关联连接。可用 `--demo` 查看合成数据，用 `--jaccount` 在终端登录，或设置 `SJTU_HPC_API_TOKEN` 预设访问令牌。需要网络代理时设置 `HPC_PROXY` 或 `--proxy`。在终端按 Ctrl+C 可停止服务。

如果地址栏显示文件路径，请改用 PowerShell 启动服务后打印的本地网址。直接打开 `frontend/index.html` 时，页面请求无法到达后端。

服务默认读取系统代理设置。若网页提示本地服务的外网连接受到权限限制，请在普通 PowerShell 里启动服务。若提示已配置的代理无法连接，请核对代理监听地址和端口。

热图打开时约每 10 秒读取当前视图。点「刷新数据」会立即重新向数据源查询。上游采样频率和请求耗时决定实际新鲜度。失败时页面保留上次结果并显示查询时间。

最近完成视图展示最近五分钟内完成的作业，CPU 效率为整个作业的平均值。记账不足或校验未通过时，页面显示「暂无可信效率」。运行中视图显示当前运行作业。灰色斜纹表示效率缺少可信数据。

## 给队友的计算接口

Python 代码可从仓库根目录导入 `from core.efficiency import calculate_job_efficiency`，传入完整的 Slurm 作业记账字典。返回 `efficiency`（0—1 或 null）、`cpu_seconds`（秒或 null）和 `reason`（说明或 null）。挂起时的口径见 [数据口径](../docs/数据口径.md)。

服务运行时也可向 `http://127.0.0.1:8765/api/v1/cpu-efficiency` 发送 POST，JSON 请求体直接传入单条 accounting 作业记录，返回上述三个字段。此接口只做计算，不向 HPC 发送数据。调用方负责只向本机服务提供已授权的数据。

方格数据接口为 `GET /api/v1/job-heatmap?view=completed` 或 `view=running`，包含查询时间、源更新时间（无则 null）和作业摘要。智能体诊断使用同一浏览器连接。 [接口约定](../docs/接口约定.md)
