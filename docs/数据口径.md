# 数据口径（初稿）

依据：2026-11-22 用户转述的超算平台工作人员答复；尚未取得 API 与 sacct 对照样例。

- 作业 CPU 时间：累计有效步骤 `time.total`；排除 `extern`；`batch` 仅含脚本自身。普通步骤 CPU 时间为零的原因尚未确认，不能直接判为 0% 利用率。
- 有效运行时间：`elapsed - suspended`；`elapsed` 包含挂起。`start=4294967294` 表示从未开始。
- 步骤级 `tres.requested.max` 中 `type=mem` 是单任务 MaxRSS，单位字节，`node/task` 标识峰值任务；不能直接当作作业总峰值。
- 作业级 `tres.allocated`、`tres.requested`、`required.*` 及步骤级 `tres.allocated` 的内存单位为 MB；步骤级 `tres.requested.*`、`tres.consumed.*` 为字节。MB 的换算约定需核对。
- 固定 CPU 分配且统计完整时，作业平均 CPU 效率可按累计 CPU 时间除以分配 CPU 数与有效运行时间的乘积计算。分配变化、步骤缺失、重启/重新排队需单独核实。
